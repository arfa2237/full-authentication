{% trans "Mumps (Epidemic Parotitis)" %}

{% trans "Overview" %}

{% trans "Mumps is a contagious viral infection caused by the paramyxovirus. It is best known for the painful swelling of the salivary glands, particularly the parotid glands (parotitis). Mumps was a common childhood disease before the introduction of the mumps vaccine." %}

{% trans "The mumps vaccine has been available since 1967. The MMR vaccine provides about 88% protection against mumps after two doses. While mumps is usually mild in children, it can cause serious complications in adolescents and adults, including infertility in males." %}

{% trans "Before the mumps vaccine, nearly everyone got mumps during childhood. Since vaccination programs began, mumps cases have decreased by more than 99% in countries with high vaccination coverage. However, outbreaks still occur, particularly in close-contact settings like schools and colleges." %}

88%

15-30%

{% trans "Symptoms of Mumps" %}

{% trans "Symptoms typically appear 12-25 days after exposure to the virus." %} {% trans "About one-third of infected people have mild or no symptoms." %}

{% trans "Early Symptoms" %}

{% trans "Fever, headache, muscle aches, tiredness, loss of appetite, and general malaise" %}

{% trans "Parotitis (Swollen Glands)" %}

{% trans "Painful swelling of one or both parotid glands (salivary glands located below the ears and jaw)" %}

{% trans "Pain While Chewing" %}

{% trans "Swelling causes pain and tenderness when chewing, swallowing, or drinking acidic liquids" %}

{% trans "Fever Pattern" %}

{% trans "Low to moderate fever (101-103°F) that typically lasts 3-4 days" %}

{% trans "Contagious Period" %}

{% trans "From 2 days before to 5 days after salivary gland swelling begins" %}

{% trans "Duration" %}

{% trans "Illness typically lasts 7-10 days, with swelling gradually subsiding" %}

{% trans "Prevention & Vaccination" %}

{% trans "MMR Vaccine" %}

{% trans "Primary Prevention" %}

{% trans "Two doses: First at 12-15 months, second at 4-6 years" %}

{% trans "88% effective against mumps" %}

{% trans "Outbreak Control" %}

{% trans "Third Dose" %}

{% trans "During outbreaks, a third MMR dose may be recommended for high-risk groups" %}

{% trans "Especially in college settings" %}

{% trans "Isolation" %}

{% trans "During Illness" %}

{% trans "Stay home for 5 days after gland swelling begins to prevent spread" %}

{% trans "Avoid contact with unvaccinated individuals" %}

{% trans "Healthcare Workers" %}

{% trans "Required Immunity" %}

{% trans "Healthcare personnel should have documented immunity to mumps" %}

{% trans "Two doses of MMR vaccine recommended" %}

{% trans "Complications of Mumps" %}

{% trans "Mumps complications are more common in adolescents and adults" %} {% trans "than in children. While mumps is usually mild, complications can be serious and permanent." %}

{% trans "Orchitis" %}

{% trans "Testicular inflammation occurs in 15-30% of post-pubertal males. Can cause testicular atrophy and rarely sterility." %}

{% trans "Oophoritis" %}

{% trans "Ovarian inflammation in 5% of post-pubertal females. Causes lower abdominal pain and fever." %}

{% trans "Meningitis" %}

{% trans "Viral meningitis occurs in 1-10% of mumps cases. Usually resolves without long-term problems." %}

{% trans "Encephalitis" %}

{% trans "Brain inflammation occurs in 1 in 6,000 cases. Can cause permanent neurological damage." %}

{% trans "Hearing Loss" %}

{% trans "Sudden sensorineural hearing loss in about 1 in 20,000 cases. Usually permanent and unilateral." %}

{% trans "Pancreatitis" %}

{% trans "Inflammation of the pancreas occurs in about 4% of cases. Causes severe abdominal pain." %}

{% trans "WHO Global Impact Data:" %}

{% trans "Before vaccination, mumps was a common childhood disease with annual epidemics. Since the introduction of the mumps vaccine, cases have decreased by over 99% in countries with high vaccination coverage. However, mumps still causes outbreaks, particularly among young adults in close-contact settings like schools and universities." %}
